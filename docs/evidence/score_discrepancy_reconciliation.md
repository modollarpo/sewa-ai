## 1. Root Cause of Score Discrepancy

The classifier scores in `conformal_routing_table.csv` (Source A) and
`v2a1_fn_safety_interception.json` (Source B) differ **solely due to aggregation method**.
Both sources use the identical model checkpoint (`classifier_v2a1.pt`),
no AdaBN, and no temperature scaling on the study-level score.

| Property | Source A (routing table) | Source B (interception audit) |
|---|---|---|
| Checkpoint | `classifier_v2a1.pt` | `classifier_v2a1.pt` |
| AdaBN | None | None |
| Temperature scaling | None | None |
| **Aggregation** | **MAX probability slice per study** | **MEAN of TOP-3 slices by prob** |
| Generated by | `conformal_reconciliation_audit.py` | `audit_fn_safety_interception.py` |

> [!IMPORTANT]
> MAX ≥ TOP-3 MEAN by definition. Source A scores are consistently higher.
> This explains every discrepancy in the table below.
