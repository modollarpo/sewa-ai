## Key Priorities

### Design System
Before making more UI changes, build a formal design system with:
- Color tokens
- Typography scale
- Button variants
- Card components
- Tables
- Charts
- Form controls
- Notification styles
- AI confidence badges
- Status indicators
- Icons
- Modal patterns
- Navigation patterns
- Responsive grid
- Accessibility standards

### Product UX Audit
Review every workflow, asking:
- Can a radiologist complete this task in the fewest possible steps?
- Is uncertainty always visible?
- Is the AI's reasoning easy to understand?
- Are clinician actions clear?
- Is the audit trail accessible?
- Does the interface reduce cognitive load?
- Are critical alerts immediately distinguishable?
- Does the experience support both routine and urgent cases?

## Pricing Strategy

### Enterprise Pricing Floor
- Starting from £4,999/month
- Unlimited scans
- Dedicated infrastructure
- Regulatory submission support

### Starter Clinic
- Annual-only plan (reduces churn, improves cash flow)
- 15% discount vs monthly billing

### Africa Programme
- 60-80% discounted pricing
- Dedicated page with local currency support (NGN, KES, GHS, ZAR, TZS, RWF)
- Offline-first deployment option
- Local language support (English, Swahili, Yoruba)

### Outcome-Based Pricing Pilot
- Post-NIHR EME
- Offer "pay for door-to-alert time improvement" as an Enterprise option
- Differentiates SEWA AI from competitors and aligns pricing with value
