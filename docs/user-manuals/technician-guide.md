# SEWA AI — Technician User Guide

## 1. Getting Started
- **Accessing SEWA**: Navigate to your institution’s SEWA URL, e.g., `https://royal-london.sewaxai.health`
- **Logging In**: Use your institutional email and password. If your hospital requires MFA, complete that step as well

## 2. Scan Upload Workflow
- **Step 1: Select Patient**: Search for patient by MRN, name, or NHS number
- **Step 2: Enter Scan Details**: Select modality (CT, MR, XR, US), body part, priority (STAT/urgent/routine), and add any relevant notes
- **Step 3: Upload DICOM**: Drag & drop DICOM files or folders, or use the browse button
- **Step 4: Verify**: Review upload status, confirm scan metadata, and submit
- **Step 5: Real-time Updates**: Use the mobile app or web interface to track scan processing

## 3. DICOM Node Integration (Optional)
If your hospital has PACS integration, scans will automatically route to SEWA without manual upload! Contact your IT team to set up or troubleshoot DICOM node configuration.

## 4. Troubleshooting Common Issues
- **Upload failed**: Check network connection, retry, or use low‑bandwidth compressed DICOM mode
- **Duplicate scan**: Use accession number to check if scan already exists
- **Scan stuck in processing**: Wait 10 minutes; if still stuck, contact support

## 5. Help & Support
- Use the help button in the app or visit `https://support.sewaxai.health`
- Create a support ticket via the in‑app support portal
